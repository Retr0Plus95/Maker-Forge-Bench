# Bench Forge (working name)

A soldering drawing viewer for any electronics project: zoom into schematics and board layouts,
find a part, flip to the solder side, tick off what's done, and ask Claude about a part. It runs in
your browser on PC, phone and tablet, with no account and no uploads. It sits alongside
[Maker Forge](https://github.com/Retr0Plus95/Maker-Forge).

**Status:** design stage, nothing built yet.
