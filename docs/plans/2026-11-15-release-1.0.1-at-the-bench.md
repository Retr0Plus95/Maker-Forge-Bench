# Bench 1.0.1 "At the bench" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Batch 1 of the 50 ideas: twelve helps at the bench (welcome back, time left, iron reminder,
sort your parts, joints and solder, tools, tips, waiting parts, buzz, undo toast, mix-up warning,
bridge risk).

**Architecture:** Each idea's logic lives in a small pure module with node:test unit tests
(`src/bridges.js`, `src/benchtips.js`, `src/waiting.js`, `src/resume.js`, `mixUps` in
`src/markings.js`); `src/app.js` wires it to the page and `src/panel.js` draws it with `el()`.
Every change goes through `history.do`; new progress fields are optional and cleaned on import.

**Tech Stack:** ES modules, strict CSP, Trusted Types `bench-svg`, three.js r128; node:test unit
tests; Playwright browser tests in Edge (`tests/browser/harness.js`).

**Spec:** `docs/design/2026-11-15-release-1.0.1-design.md`

## Global Constraints

- Pages are built with `el()` only, never innerHTML; Trusted Types policy `bench-svg` only.
- Every change a person makes goes through `history.do` (undoable); views are not changes.
- Storage keys stay `bench.*`; `deploy/csp.txt` unchanged; nothing needs anything local.
- New progress fields are optional: an older progress file still opens; bad entries are dropped.
- Plain words in everything the builder reads.
- `bash check.sh` ends with ALL CHECKS PASSED before the release is offered for merge.
- Run `npm test` (unit) per task; browser tests per file with
  `node --test --test-concurrency=1 tests/browser/<file>.test.js`.

## Review Focus

1. A project without `board` (drawings only): every new line hides itself, nothing throws.
2. A part marked waiting, then the project file drops that part: the Waiting step ignores it.
3. All parts of a step waiting: the step leaves the list and the open step follows its id.
4. Undo toast after the history moved on (another change came after the tick): Undo does nothing.
5. Iron reminder with the page hidden or no tick this visit: no reminder.

Tests for each are added to the task that owns the code (Tasks 1, 5, 5, 7, 8).
