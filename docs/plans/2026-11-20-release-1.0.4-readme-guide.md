# Bench 1.0.4 "How to build it" Implementation Plan

> Native execution: implemented in this session, test first, one self-review of the branch at the end.

**Goal:** Bench reads the project's README.md and shows its wiring, assembly and first power-up sections as
steps to tick, each with its wires from the drawing and a picture cropped from the drawing, behind a mains
safety list.

**Architecture:** `src/readme.js` (no page code) reads Markdown into blocks and a guide (sections, steps,
wires per step, crops, needs, the safety list). `src/guide-panel.js` draws the section with `el()`.
`src/app.js` loads the README from the source, keeps ticks in `state.drawing.steps/safety`, and reuses
1.0.3's rings for a step's wires.

**Spec:** `docs/design/2026-11-20-release-1.0.4-design.md`

## Global constraints

- `deploy/csp.txt` unchanged; no innerHTML; every change through `history.do`; storage keys `bench.*`.
- Works from dev.py, a GitHub link and a picked folder.
- README at most 256 KB; Markdown at most 5 000 blocks.
- Safety list text exactly as design §6.5.

## Review focus

1. A README with no matching sections, or none at all: nothing new shows except the safety list for a
   mains drawing; no errors.
2. HTML or script in the README shows as text, never as markup.
3. A web picture (`https://…`) is never fetched; it shows as its link text.
4. Live reload: a README edited on disk is read again; ticks of steps that still exist stay.
5. Undo after ticking a step or safety line puts it back; Start over clears both.

## Tasks

### Task 1: Markdown reader — `src/readme.js`

- `parseMarkdown(text) → Block[]`: `{t:'h',level,text}`, `{t:'p',text}`, `{t:'list',ordered,start,items:[{text,blocks}]}`,
  `{t:'table',head:[],rows:[[]]}`, `{t:'quote',blocks}`, `{t:'hr'}`.
- `inline(text) → Run[]`: `{t:'text'|'b'|'i'|'code',text}`, `{t:'link',text,href}`, `{t:'img',alt,src}`; bold may hold italic text flattened.
- Tests `tests/unit/readme.test.js`: headings/paragraphs; numbered list with nested bullet list and a
  continuation paragraph; table with alignment row; quote; inline runs incl. `**OUT −**`, `` `code` ``,
  `[a](b)`, `![x](images/a.png)`; `<script>` kept as text; 5 000 block cap.

### Task 2: The guide — `src/readme.js`

- `readGuide(text) → { sections: Section[] }`, Section `{ id, kind:'steps'|'read', role:'wiring'|'assembly'|'power'|'safety'|'trouble', heading, before:Block[], steps:Step[], after:Block[] }`,
  Step `{ id:'readme:<slug>:<n>', n, blocks, text, wires:string[], terms:string[] }`.
- `stepWires(step, role, reads) → [{ sheetId, wire, by:null|string }]` (design §6.3).
- `cropFor(read, texts, wireIds, viewBox) → {x,y,w,h}|null` (design §6.4).
- `guideNeeds(guide, reads, hasFile) → [{ id, kind, text }]` ids `readme:wire:<step>:<W>`, `readme:pic:<src>`, `readme:left`.
- `mentionsMains(text)`, `SAFETY` (7 `{id,text}`), `pickReadme(files)`, `MAX_README = 256*1024`.
- Fixture `tests/fixtures/psu-like/README.md` modelled on the PSU README (wiring, assembly, power-up,
  safety, troubleshooting). Tests: sections and roles; steps of Wiring; W numbers named; AC24V/thick
  black/header U matching against the fixture drawing; leftovers; needs; crop inside the viewBox and
  wider than high; pickReadme top-level first.

### Task 3: Progress, sources, dev.py

- `isProjectFile` accepts `README.md` (any case); dev.py lists `README.md` (any case) as `text/markdown; charset=utf-8`.
- Tests: drawing.test.js progress, sources test, `tests/python/test_dev.py`.
