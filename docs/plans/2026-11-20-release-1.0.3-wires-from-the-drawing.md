# Bench 1.0.3 Wires from the drawing: implementation plan

**Goal:** Bench reads the text of drawings it couldn't read (labels kept as comments), reads a drawing's
wire table, checks list and notes, shows a wire list to tick, the drawing's checks, and what it needs.

**Architecture:** a new page-free module `src/drawing.js` (text with a place, rows, the tables, the
ends, the needs), unit-tested on xmldom; `search.js` indexes comment labels; `app.js` keeps the ticks and
answers in progress like the fault finder's; `panel.js` gets `renderWires`.

**Spec:** `docs/design/2026-11-20-release-1.0.3-design.md`

## Global constraints
- Pages built with `el()` only, never innerHTML. Trusted Types `bench-svg` only. `deploy/csp.txt` unchanged.
- Every change through `history.do`. Storage keys stay `bench.*`.
- No AI except the last-resort Copy for Claude.
- Projects with a board (the fume extractor) look and behave exactly as before.

## Review focus
1. A drawing with a wire table but no tags at all: one item, not one per wire.
2. Wrapped note lines and wrapped check sentences join their item.
3. A drawing edited and re-read (live refresh) keeps ticks by wire number.
4. Two drawings with tables: each wire list is its own (keyed by sheet).
5. Odd input: an empty table, a header with no rows, huge comments (capped).

### Task 1: text with a place (`src/drawing.js` `sheetTexts`, `src/search.js`)
- `sheetTexts(root) → [{ text, x, y, size, el }]` in document order; comments before letter groups.
- `indexSheet` also returns comment labels (el = the letter group).
- Tests: `tests/unit/drawing.test.js` on a small matplotlib-like SVG fixture
  (`tests/fixtures/psu-like/wiring.svg`) and the KiCad-like one.

### Task 2: the tables and the needs (`src/drawing.js`)
- `rowsOf(texts)`, `readWireTable(texts)`, `readChecks(texts)`, `readNotes(texts)`, `endsOf(cell)`,
  `expectedVolts(text)`, `readDrawing(sheetId, texts) → { wires, checks, notes, tags, testPoints, partRefs }`,
  `drawingNeeds(reads, { hasBoard, unreadable }) → [{ id, kind, text, sheetId, wires, question?, fixInDrawing }]`,
  `cleanWireProgress(raw)`.
- Tests: every need kind, wrapped lines, several ends, mains grouping, volts.

### Task 3: the page (`src/app.js`, `src/panel.js`, `src/index.html`, `src/style.css`, `src/checklist.js`)
- `#wires` section first in the Wiring tab; `renderWires`; ticks `Wired W9`, answers, Not needed.
- Checks tab gets the drawing's checks; Show rings tags, ends and test points.
- Progress field `drawing: { done: [...], answers: {...}, dismissed: [...] }` in saved progress, versions,
  the progress file and Start over.
- Guessed parts leave out W tags and TPs. APP_VERSION 1.0.3; What's new.
- Browser tests: `tests/browser/drawing.test.js` on `tests/fixtures/psu-like/`.

### Task 4: docs and the full check
