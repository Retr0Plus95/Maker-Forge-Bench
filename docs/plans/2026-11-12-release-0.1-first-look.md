# Maker Forge Bench 0.1 "First look" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `python dev.py <project folder>` opens that folder's drawings in the browser, with sheet
tabs, zoom and pan, Find part across all sheets, flip to the solder side and auto-refresh. Every SVG
is cleaned before it is shown.

**Architecture:** A static page of ES modules in `src/` (no build step in 0.1). A standard-library
Python server serves it together with the project folder, and pushes file changes to the page over
Server-Sent Events. The logic with no page code (`sanitize.js`, `project.js`, `zoom.js`,
`search.js`) is unit-tested in Node. The page code (`viewer.js`, `app.js`, `findbar.js`, `live.js`,
`sources.js`) is tested in the installed Chrome through Playwright.

**Tech Stack:** HTML, CSS and JavaScript ES modules; Python 3.10+ standard library; Node 24
(`node --test`); two dev-only npm packages, `@xmldom/xmldom` (an XML DOM for the Node tests) and
`playwright` (drives the installed Chrome with `channel: "chrome"`, so no browser download); Git
Bash for `check.sh`.

**Spec:** `docs/design/2026-11-12-maker-forge-bench-design.md` (§4, §5, §7.1–7.3, §7.6, §7.9, §8,
§9, §10, §11) and `ROADMAP.md` release 0.1.

**Repo:** `G:\Bench-Forge` (GitHub `Retr0Plus95/Maker-Forge-Bench`), branch `main`. Test project:
the fume extractor, `G:\Solder Fume Extractor\Solder-Fume-Extractor` (Rev D, commit 96c7316).

## Global Constraints

- `src/index.html` has no inline scripts, no `style` attributes and no `<style>` elements. Page
  elements are built with `createElement`, `textContent` and `setAttribute`; never `innerHTML`,
  `outerHTML`, `insertAdjacentHTML` or `document.write`.
- Every `dev.py` response carries this CSP, read from `deploy/csp.txt` (one line):
  `default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' blob: data:; connect-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'none'; require-trusted-types-for 'script'; trusted-types bench-svg`.
  Later releases add the GitHub and Anthropic addresses from design §8 when they start using them.
- The only Trusted Types policy is `bench-svg`, created in `src/app.js` and used only to pass SVG
  text to `DOMParser`. Its output is an inert document that `sanitize.js` cleans before anything
  reaches the page.
- Limits: 25 MB per file (`26214400` bytes) and 200,000 elements per sheet.
- `dev.py`: Python 3.10+, standard library only. It binds `127.0.0.1` only and serves only files
  inside the project folder.
- Search indexes every `<text>`, including invisible ones: KiCad 9 writes each label as
  `<text opacity="0">` over the lines it draws.
- Messages name the file and say what to try, in plain words (design §9). Use the exact wording
  wherever this plan quotes it.
- 0.1 is for the PC (mouse and keyboard). Phone gestures, themes and Easy reading come in 0.3. Use a
  plain dark page for now (background `#111`, text `#eee`).
- UTF-8 and LF line endings. Commit after every task, and end each commit message with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `bash check.sh` runs everything and ends with `ALL CHECKS PASSED`.

**Interfaces:**
- Produces (HTTP, used by `sources.js` and `live.js`):
  - `GET /` serves `src/index.html`, and `GET /<name>` serves `src/<name>` (no subfolders in 0.1).
  - `GET /api/files` returns `{"root": "<folder name>", "files": [{"path": "docs/layout/SFE-04_Perfboard_Layout.svg", "size": 193955, "mtime": 1731400000.25}]}`.
    Paths are relative and use `/`. It lists files ending `.svg`, `.png`, `.jpg` or `.jpeg` (any
    case) and files named `forge-project.json`. It skips folders whose names start with `.` and
    `node_modules`, and sorts by `path.casefold()`.
  - `GET /project/<url-encoded relative path>` returns the file with `Content-Type`
    `image/svg+xml`, `image/png`, `image/jpeg` or `application/json`. Any other type, a missing
    file or a path outside the folder gives 404.
  - `GET /api/events` is a `text/event-stream`. It sends `event: change` with
    `data: {"path": "...", "mtime": ...}` for a new or changed file, `event: remove` with
    `data: {"path": "..."}` for a deleted one, and `: ping` every 15 s. It checks the folder every
    0.5 s.
  - Every response carries the CSP header, `X-Content-Type-Options: nosniff` and
    `Cache-Control: no-store`. Only GET and HEAD are allowed (others get 405), and a disallowed
    `Host` gets 403.
  - Command line: `python dev.py <project folder> [--port 8765]`, where `--port 0` picks a free
    port. On start it prints exactly one flushed line:
    `Maker Forge Bench: http://127.0.0.1:<port>/ (serving <folder>)`.
  - Python functions:
    - `list_files(root: Path) -> list[dict]`
    - `resolve_project_path(root: Path, url_path: str) -> Path | None`, where `url_path` is the part
      after `/project/`, still URL-encoded
    - `host_allowed(host: str | None, port: int) -> bool`
    - `diff_snapshots(old: dict[str, float], new: dict[str, float]) -> list[tuple[str, str]]`, which
      returns `("change", path)` and `("remove", path)` pairs sorted by path
    - `make_server(root: Path, port: int) -> ThreadingHTTPServer`

**Interfaces:**
- Produces:
  - `export const LIMITS = { maxBytes: 26214400, maxElements: 200000 }`
  - `export class SheetError extends Error`, created as `new SheetError(code, message)`, with
    `.code` one of `'too-big' | 'entities' | 'broken' | 'not-svg' | 'too-many-elements'`
  - `export function prepareSvg(text: string, parser: { parseFromString(text: string, type: string): Document }, name: string, byteSize = text.length): { doc: Document, removed: number, elements: number }`.
    It runs, in this order:
    1. the size check, before parsing;
    2. the entity check: `<!ENTITY`, or a `<!DOCTYPE` with an internal subset `[`;
    3. parsing, where anything thrown becomes `broken`;
    4. the root check: a `parsererror` element anywhere means `broken`, and a root that isn't `svg`
       in the SVG namespace means `not-svg`;
    5. cleaning, counting elements as it walks; over the limit means `too-many-elements`.
  - `export function sanitizeSvgDocument(doc: Document): { removed: number, elements: number }`
    changes the document in place. `removed` counts the elements and attributes taken out.
  - `tests/unit/helpers.js`:
    - `nodeParser()`: an xmldom `DOMParser` that throws on parse errors (`onError`)
    - `serialize(doc)`
    - `readFixture(relPath)`
    - `FUME_SVGS`: the five fixture paths relative to `tests/fixtures/`, in the order listed
      under Files, so `FUME_SVGS[3]` is SFE-04
- Messages (exact; `<name>` is the file name without its folders):
  - too-big: `<name> is bigger than 25 MB, so it wasn't opened. Export it again with fewer details, or split it into sheets.`
  - entities: `<name> uses XML entity declarations, which can freeze the page, so it wasn't opened. Export it again from your drawing program.`
  - broken: `<name> couldn't be read: the file is broken or only half-saved. Save it again.`
  - not-svg: `<name> isn't an SVG drawing.`
  - too-many-elements: `<name> has more than 200,000 shapes, so it wasn't opened. Export it with fewer details, or split it into sheets.`
- Cleaning rules (design §8, made exact):
  - **Elements kept** (SVG namespace only): `svg g defs symbol use title desc text tspan textPath path rect circle ellipse line polyline polygon image clipPath mask pattern marker linearGradient radialGradient stop style`.
  - **Unwrapped** (children kept, the element itself removed): `a`, `switch`.
  - **Removed with their children:** every other element, including `script`, `foreignObject`,
    `animate`, `set`, `metadata` and elements in any other namespace (Inkscape's, Sodipodi's).
  - **Attributes kept** (no namespace): `id class style transform x y x1 y1 x2 y2 cx cy r rx ry fx fy width height d points pathLength viewBox preserveAspectRatio fill fill-opacity fill-rule stroke stroke-width stroke-opacity stroke-linecap stroke-linejoin stroke-dasharray stroke-dashoffset stroke-miterlimit opacity font-family font-size font-weight font-style font-variant text-anchor dominant-baseline alignment-baseline baseline-shift letter-spacing word-spacing text-decoration textLength lengthAdjust dx dy rotate startOffset clip-path clip-rule mask marker-start marker-mid marker-end offset stop-color stop-opacity gradientUnits gradientTransform spreadMethod patternUnits patternContentUnits patternTransform markerWidth markerHeight markerUnits refX refY orient clipPathUnits maskUnits maskContentUnits visibility display color vector-effect shape-rendering text-rendering image-rendering version baseProfile href`.
    Also kept: `xlink:href`, `xml:space`, and the namespace declarations `xmlns` and `xmlns:xlink`.
    Other namespace declarations (`xmlns:inkscape` and so on) are removed.
  - **`href` and `xlink:href`:** on `image`, only values starting `data:image/png;base64,`,
    `data:image/jpeg;base64,`, `data:image/gif;base64,` or `data:image/webp;base64,`. Everywhere
    else, only values starting with `#`. Any other value removes the attribute, and an `image` or
    `use` left without one is removed.
  - **Styles:** a `style` attribute or `style` element is removed if it contains a backslash, the
    text `@import`, or any `url(` not followed by optional spaces and quotes and then `#`. The same
    `url(` rule applies to every kept attribute value.

**Files:**

**Interfaces:**
- Consumes: the `files` array from `GET /api/files` (Task 1).

  - `Sheet = { id: string, label: string, path: string, type: 'svg' | 'png' | 'jpg', kind: 'schematic' | 'layout' | 'photo', size: number, mtime: number }`
- Rules:
  - Drawings are files ending `.svg`, `.png`, `.jpg` or `.jpeg` (any case).
  - When the same name without its extension (case ignored) appears in several places, it becomes

  - `kind` is `photo` for JPG. Otherwise it's `layout` if the path matches
    `/layout|perfboard|stripboard|pcb/i`, and `schematic` if not.
  - Order: `a.id.localeCompare(b.id, 'en', { numeric: true, sensitivity: 'base' })`.

### Task 4: Zoom maths

**Files:**
- Create: `src/zoom.js`, `tests/unit/zoom.test.js`

**Interfaces:**
- Produces:
  - `View = { scale: number, x: number, y: number }`. A point (sx, sy) in the SVG element's own
    pixels appears in the stage at (sx·scale + x, sy·scale + y).
  - `export const SCALE_LIMITS = { min: 0.02, max: 40 }`
  - `export function svgSize(a: { viewBox: string | null, width: string | null, height: string | null }): { x: number, y: number, w: number, h: number } | null`.
    The viewBox wins (numbers split on spaces and/or commas, with w and h > 0). Otherwise it uses
    width and height, with units converted to px: `px` or none is 1, `mm` is 96/25.4, `cm` is
    96/2.54, `in` is 96 and `pt` is 96/72. `%` gives `null`. With neither, it returns `null`.
  - `export function fitView(sheet: { w, h }, box: { w, h }, margin = 16): View` shows the whole
    sheet, centred.
  - `export function zoomAt(view: View, factor: number, px: number, py: number): View` keeps the
    sheet point under (px, py) in place, with the scale clamped to `SCALE_LIMITS`.
  - `export function panBy(view: View, dx: number, dy: number): View`
  - `export function zoomToRect(rect: { x, y, w, h }, box: { w, h }): View` centres the rect at
    scale `min(box.w, box.h) / (max(rect.w, rect.h) * 12)`, clamped.
  - `export function wheelFactor(deltaY: number, deltaMode: number): number` returns
    `Math.exp(-d * 0.0015)`. `d` is `deltaY` for mode 0, `deltaY * 16` for mode 1 (lines) and
    `deltaY * 400` for mode 2 (pages).
