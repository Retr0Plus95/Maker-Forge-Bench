# Bench 1.0: Wire to cut, Shape's modules, Send to Shape: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the three features 1.0 takes from Maker Forge Shape:
- lengths to cut for every wire;
- Shape's 62 boards and modules as library models;
- a Send to Shape button that puts your board into Shape's box maker.

**Architecture:**
- Each feature has a pure module, unit-tested in Node: `src/wirecut.js`, a module spec in `tools/kicad3d.py` plus `src/modules.js`, and `src/shape-send.js`.
- Only thin wiring goes into `app.js`, `panel.js` and `index.html`, tested in the browser.
- The module data is copied once from Shape into `tools/shape-boards.json`. `tools/kicad3d.py` builds GLBs from it, the same way it builds our own models.

**Tech Stack:**
- ES modules in the browser, under a strict CSP with Trusted Types.
- three.js r128 (unchanged).
- Python 3.10, standard library only, for the library tool.
- Node `node:test` for unit tests; Playwright with Edge for browser tests.

**Spec:** `docs/design/2026-11-15-release-1.0-design.md` (approved 2026-11-15). Section 5 of the spec, the launch work, is not in this plan.

**Work in:** a worktree `G:/Bench-Forge-1.0` on a new branch `release-1.0`, cut from `main`. Commit and push the branch after each task (the owner's standing rule). Merge to main only when the whole plan is done and reviewed.

## Global Constraints

- `deploy/csp.txt` doesn't change.
- Pages are built only with `el()`, never innerHTML.
- Trusted Types stay `bench-svg` only.
- Project changes go through `history.do`. Wire to cut changes nothing. Send to Shape is not an undo step (spec §4).
- Bench's own storage keys stay `bench.*`. The only other key Bench may write is Shape's `makerforge.parts`.
- Library limits:
  - under 8 MB in all (`MAX_TOTAL`);
  - each model under 250 KB;
  - each module model aims under 8 KB.
- No change to Shape's repo (`G:\Maker-forge`). Its code and data come over as copies, credited to Shape at commit `b6e372b` (MIT).
- Everything works on the website with nothing installed. Send to Shape sends only at `forge.retr0plus.se` (spec §4).
- Plain words in every new text, as the spec writes them ("cut 15 mm, strip 5 mm at each end").
- Browser tests:
  - `openPage(url, viewport, options)`, with `realParts` and `before` in the **third** argument;
  - they run in Edge;
  - don't edit `src/` while `check.sh`'s browser tests run.
- `check.sh` must end `ALL CHECKS PASSED`. At 0.9 that was 36 Python, 231 unit and 349 browser tests.

## Review Focus

1. **A link whose path repeats a hole, or has a zero-length step.** Its length is just the two ends (10 mm), never NaN. Test in Task 1.
2. **Shape's Your parts in this browser holds something Bench can't read** (bad JSON, not a list). Bench refuses and leaves it exactly as it was. Test in Task 5.
3. **A part value that contains two module names** ("ESP32-CAM", "ESP32 DevKit V1"). The longest name wins. Test in Task 4.
4. **A project name that's long or has `< > & "` in it.** The label is cleaned and at most 20 characters, which Shape accepts. Test in Task 5.
5. **Send to Shape opened before the 3D board was ever opened.** The height still comes filled in, from Bench's own part shapes, never 0 or empty. Test in Task 6.

### Task 1: Wire lengths (pure)

**Files:**
- Create: `src/wirecut.js`
- Test: `tests/unit/wirecut.test.js`

**Interfaces:**
- Consumes: a normalised project board from `parseProject(...).board`:
  - `pitch`, `parts` (`{ ref: { pins: { name: [c, r] } } }`), `nets` (`{ net: [[ref, pin]] }`), `netLabels`;
  - `links` (`[{ path: [[c, r]...] }]`), `buses` (`[{ row, from, to, net, label }]`);
  - and `suggestAll()` groups from `src/boardcheck.js`: `[{ net, label, kind: 'power'|'ground'|'signal', wires: [{ path }] }]`.
- Produces:
  - `END_MM = 5`, `STRIP_MM = 5`, `STEP_MM = 5`.
  - `pathMm(path, pitch = 2.54): number`: each step's true distance in holes × pitch.
  - `cutMm(path, pitch = 2.54): number`: `ceil((pathMm + 2·END_MM) / STEP_MM) · STEP_MM`. Guard against float noise (37.62 must not become 40.0001 → 45).
  - `holeNets(board): Map<'c,r', string>`: line labels (netLabels[net] or net). Parts' pins in `nets` come first; then bus rows fill any hole not yet named. This is sheet 4's own rule in `render.py`.
  - `wireCut(board)` returns:
    - `links: [{ n, from: [c,r], to: [c,r], line: string|null, cut, strip: 5 }]`;
    - `buses: [{ row, from, to, line, cut }]`;
    - `totals: { insulated: { count, mm }, bare: { count, mm } }`.
    - `n` is the 1-based position in `board.links`. Sheet 4 numbers its wire list the same way: `render.py` and `export_board.py` both walk `B["links"]` in order. Checked 2026-11-15.
    - A link's line is the one at its first hole, else at its last hole.
    - A bus is cut as the path `[[from, row], [to, row]]`.
  - `suggestedCut(groups, pitch = 2.54)` returns `{ lines: [{ net, label, colour: 'red'|'black'|null, wires: [{ path, cut }], mm }], totals: { red, black, other } }`. power → red, ground → black, signal → null.
  - `lengthText(mm): string`:
    - under 1000 mm: `about ${ceil(mm / 50) · 5} cm`;
    - otherwise `about ${(ceil(mm / 100) / 10).toFixed(1)} m`.
    - Rounded up, so nobody cuts short.
  - `wireCutText(cut, suggested = null): string`: the list as plain text, for Copy.

- Create: `src/modules.js`

- Test: `tests/unit/library-match.test.js`, new `tests/unit/modules.test.js`, new `tests/browser/modules.test.js`

**Interfaces:**
- Consumes (Task 3): index entries of kind `module`, with `fit.value`, `fit.also`, `footprint.pins` (maybe `[]`) and `module`.
- Produces:
  - `modelFor` for `type: 'module'`: among module entries, the one whose longest name (`fit.value` or any of `fit.also`) is contained in the part's value, case-insensitive. Ties go to the earlier entry; none gives `null`.
  - `placeFor`: a module part with no `keepout`, given an entry with no pins, goes to `placeInOutline(entry, box)`. The box is its holes' bounding box (from `holesFor`), half a pitch wider all round.
  - `modelsThatFit` for a module part:
    - with a `keepout`, every module entry fits, because it's placed in that outline whatever its pins;
    - without one, an entry with no pins fits (centred over the holes), and a pinned entry keeps today's rule (same pin count, lands on the holes).
  - `src/modules.js`:
    - `PORT_WORDS`, the kinds used in the data: micro 'micro-USB', usbc 'USB-C', usbmini 'mini-USB', usba 'USB-A', usba2 'two USB-A', usbb 'USB-B', dcpcb 'DC jack', jack35 'audio jack', rj45 'network socket', hdmi 'HDMI', hdmimicro 'micro-HDMI', hdmimini 'mini-HDMI';
    - `EDGE_WORDS`: x0 left, x1 right, y0 front, y1 back;
    - `moduleFacts(entry) → { size, holes, ports, check } | null`.
  - The card adds `p#part-module`: `Module: 45 × 18 mm, no mounting holes, mini-USB on the left edge.` When `check` is set, it adds `Sizes vary between makers: measure yours.` The facts are worked out once `libraryNow` has loaded, the way the model choices are.

### Task 5: Send to Shape: the board in Shape's own form (pure)

**Files:**
- Create: `src/shape-send.js`
- Test: `tests/unit/shape-send.test.js`

**Interfaces:**
- Consumes: a board (the project's, or `boardFromPlacement(...)` for My board), the project's part values (`{ ref: value }`), and `partGeometry` from `src/board3d-geometry.js`.
- Produces:
  - `SHAPE_HOST = 'forge.retr0plus.se'`, `SHAPE_KEY = 'makerforge.parts'`, `SHAPE_MAX = 40`, `SHAPE_URL = 'https://forge.retr0plus.se/'`.
  - `canReachShape(hostname: string): boolean`: exactly `SHAPE_HOST`.
  - `shapeId(name: string, which: 'drawing'|'mine'): string`: `'bn'` plus 6 base-36 characters of a 32-bit FNV-1a hash of `` `${name}|${which}` ``. It matches Shape's `/^[a-z0-9]{4,10}$/`.
  - `defaultSize(board): [w, d]` in mm: `((maxC − minC + 2) · pitch, (maxR − minR + 2) · pitch)` over part pins, link holes and bus ends, rounded to 0.1.
  - `simpleHeights(board): { [ref]: mm }`: the tallest point of each top-side part above the board, from `partGeometry`'s shapes:
    - cyl, box, sector, extrude, dome and standing lathe: `z0 + h`;
    - hcyl and lying lathe: `z + radius`;
    - wire: highest point's z + radius;
    - print and joint are ignored.
  - `portsAndPanel(board, values) → { ports, panel, wires }`, in Shape's frame:
    - x is `(c − minC + 1) · pitch` from the left; y is `(maxR − r + 1) · pitch` from the front; a part sits at its pins' centre.
    - **ports:** `SHAPE_PORTS` is copied from Shape's `KICAD_PORTS` with its heights, matched on `` `${type} ${value} ${package}` ``. A match within 8 mm of an edge is a port `[edge, along, kind, height]`.
    - **panel:** a top-side part that isn't a port. Shape's `KICAD_PANEL` names, plus Bench's own types:
      - led → `led3` when D is 3 or the value says 3 mm, else `led5`;
      - button → `tact`, or `tact12` when the value says 12 × 12 or 12 mm;
      - pot → `pot`;
      - switch → `toggle` when the value says toggle, else `slide`;
      - buzzer → `buzzer`.
    - **wires:** the refs of headers, terminals and connectors that are neither.
    - Parts under the board are ignored.
  - `shapeBoard(board, values, opts) → { board: ShapeBoard, wires: string[] }`:
    - `opts = { name, which, size: [w, d], holes: 'none' | { inset } | [[x, y]], screw: 'M2'|'M2.5'|'M3'|'M4', tall }`;
    - `ShapeBoard = { id, label, w, d, holes, screw, tall, ports, panel }`;
    - label: `<>&"` removed, spaces collapsed, at most 20 characters (Shape's `encWireText`);
    - `{ inset: i }` gives the four corners `[[i, i], [w − i, i], [i, d − i], [w − i, d − i]]`;
    - tall is `clamp(ceil(tall), 1, 60)`;
    - at most 16 holes, 16 ports and 32 panel parts.
  - `writeShapeParts(storage, entry)` returns `{ ok: true, replaced }` or `{ ok: false, why }`. storage is `{ getItem, setItem }`:
    - an unreadable list (bad JSON, or not an array): `"Shape's list in this browser can't be read, so Bench leaves it alone."`;
    - 40 boards and none with this id: `"Shape's Your parts is full (40 boards): remove one in Shape first."`;
    - `setItem` throws: `"This browser wouldn't keep it (storage is full or blocked)."`;
    - otherwise the entry with the same id is replaced in place, or the new one is added at the end.
